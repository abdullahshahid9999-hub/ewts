## Nai image add karni ho?
1. Is folder mein upload karo
2. Code mein path: `/assets/your-image-name.jpg`

## Hero background image add karni ho?
`hero-bg.jpg` naam se yahan daal do — developer ko batana hoga path connect karne ke liye.
